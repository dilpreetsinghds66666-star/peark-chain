# PerkChain Option 2 — Full-stack loyalty rewards + Sepolia NFT

This is an educational full-stack project with an Express backend, SQLite database, MetaMask connection and a real ERC-721 reward contract for the Sepolia testnet.

## What is real and what is not
- **Real database:** customer profile, points, voucher records, activity and confirmed NFT mint records are stored in SQLite on your computer.
- **Real testnet NFT:** after deploying the contract and configuring its address, MetaMask submits a real ERC-721 mint transaction to Sepolia. The transaction can be checked on Sepolia Etherscan.
- **Sample loyalty data:** purchases are manually recorded examples, not payments. Points and voucher codes are generated by this app. They are not authorized or accepted by Starbucks, Nike, Samsung, Adidas, BookMyShow, or Reliance Digital. No commercial brand integration is included.
- **Testnet only:** test ETH has no monetary value. Never use a wallet with valuable assets or paste a real wallet private key into the website.
- **Authentication limitation:** this student version uses a random browser customer ID, not secure login/password authentication. Do not deploy it publicly with real customer data without adding authentication, authorization, rate limits, CSRF protections, input validation and production hardening.

## Requirements
- Node.js 20+ (LTS recommended)
- MetaMask browser extension
- Sepolia test ETH from a reputable faucet (faucet availability/rules can change)
- A Sepolia RPC endpoint; the public endpoint in `.env.example` is a fallback and may be rate-limited.

## A. Run the website and database
1. Install Node.js from https://nodejs.org/
2. Extract the ZIP and open the `PerkChain` folder in VS Code.
3. Open Terminal in that folder.
4. Run:
   ```bash
   npm install
   ```
5. Copy `.env.example` to `.env`. On Windows PowerShell:
   ```powershell
   Copy-Item .env.example .env
   ```
   On macOS/Linux:
   ```bash
   cp .env.example .env
   ```
6. Start the app:
   ```bash
   npm start
   ```
7. Open http://localhost:3000
8. Test Partner offers → record a sample purchase → redeem a voucher → use/burn it. Data is saved to `data/perkchain.sqlite`.

## B. Set up a test-only Sepolia wallet
1. In MetaMask, create a new wallet/account only for this student project. Never share its recovery phrase or private key.
2. Switch MetaMask to **Sepolia test network**.
3. Get Sepolia test ETH from a reputable faucet. Test ETH is not real money.
4. For deployment, export the private key of a test-only account in MetaMask and put it only in your local `.env` as `DEPLOYER_PRIVATE_KEY=...`. Do not commit or share `.env`, screenshots of secrets, or this key.
5. Configure `SEPOLIA_RPC_URL` in `.env`. Public RPCs can be rate-limited; use a provider account if needed.

## C. Compile and deploy the NFT contract
1. Ensure `.env` has `SEPOLIA_RPC_URL` and `DEPLOYER_PRIVATE_KEY`.
2. Compile:
   ```bash
   npm run compile
   ```
3. Deploy:
   ```bash
   npm run deploy:sepolia
   ```
4. The terminal prints a contract address. Copy it into `NFT_CONTRACT_ADDRESS` in `.env` and also into `CONTRACT_ADDRESS` near the top of `public/app.js`, for example:
   ```js
   const CONTRACT_ADDRESS = "0xYOUR_DEPLOYED_CONTRACT_ADDRESS";
   ```
5. Restart the app (`Ctrl+C`, then `npm start`) and refresh the browser.

## D. Mint an actual testnet NFT
1. Open http://localhost:3000 and go to NFT collectibles.
2. Click Connect MetaMask; approve connection and switch to Sepolia when prompted.
3. Click Mint reward NFT. Confirm the transaction in MetaMask.
4. Wait for confirmation. The app stores the confirmed transaction hash and token ID in SQLite.
5. Click the Etherscan link to verify the transaction and contract on Sepolia.

The metadata URI for this classroom version is a `data:application/json;base64,...` URI, so it does not require a paid IPFS service. For durable public NFT metadata, pin the JSON and image to IPFS or another durable content-addressed store. The image used in the example is a placeholder.

## Troubleshooting
- `npm install` fails on `better-sqlite3`: install a current Node.js LTS and Windows build tools if requested, then retry.
- `npm run deploy:sepolia` says no account: check `.env` has a valid test-only `DEPLOYER_PRIVATE_KEY` (no quotes/spaces) and that it has Sepolia test ETH.
- MetaMask says wrong network: switch to Sepolia.
- Mint button says contract not configured: deploy contract and paste address into `public/app.js`.
- Browser cannot load ethers: check internet access to jsDelivr, refresh the page.
- `npm start` says port in use: change `PORT=3001` in `.env` and visit http://localhost:3001.
- `npm run compile` plugin error: run `npm install` again after checking `package.json`.
